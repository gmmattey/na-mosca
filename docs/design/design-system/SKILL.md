Read `README.md` first, then use the tokens, components, guidelines, assets and UI kit in this directory as the canonical Design System v1.
If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key facts to keep in mind for this brand specifically:
- The product's public name is **Chuta Essa!** (with exclamation) — never "Na Mosca", which is a legacy working title.
- The Design System v1 includes an official symbol and wordmark in `assets/`: use `logo-icon.svg`/`logo-icon-app.svg` and the light/dark wordmarks as the canonical v1 brand assets.
- No icon system exists — prefer text labels or simple geometric shapes over icons.
- Numbers are the visual protagonist. Cards, gradients, glow, glassmorphism, and bento grids are explicitly banned by the brand's own design rules.
