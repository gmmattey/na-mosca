Botao de acao principal do jogo, formato pill (raio total), sem sombra.

```jsx
<Button variant="primary">Chutar</Button>
<Button variant="secondary">Compartilhar</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
```

Variantes: primary (lima solido, CTA principal), secondary (contorno, sobre fundo escuro), ghost (texto apenas). disabled reduz opacidade e bloqueia clique.
