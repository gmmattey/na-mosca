Wrapper fino sobre o set Lucide (via Iconify), usado so onde texto nao resolve (voltar, fechar, compartilhar, som, configurar, copiar codigo, revanche). Nunca dentro de bolinha colorida - so o traco, cor herdada do texto ao redor.

Requer carregar uma vez por pagina: `<script src="https://code.iconify.design/iconify-icon/2.1.0/iconify-icon.min.js"></script>`

```jsx
<Icon name="arrow-left" />
<Icon name="share-2" color="var(--accent-primary)" />
<Icon name="volume-x" size={18} />
```

Icones curados para este jogo: arrow-left, x, share-2, volume-2, volume-x, sliders-horizontal, users, copy, check, rotate-ccw.
