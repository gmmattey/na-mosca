Regua abstrata que materializa a distancia entre o palpite (bolinha) e a resposta correta (traco), coracao visual da revelacao.

```jsx
<ProximityScale guessPct={70} answerPct={74} />
<ProximityScale guessPct={50} answerPct={50} exact />
```

Posicoes sao % ao longo do eixo (0-100), ja normalizadas pelo jogo a partir do erro percentual.
