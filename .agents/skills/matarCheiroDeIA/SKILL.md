# matarCheiroDeIA

Filtro obrigatório para texto e interface.

## Copy

Corte:
- introdução genérica;
- “experiência intuitiva/imersiva/envolvente”;
- três adjetivos em sequência;
- explicação do óbvio;
- emoji como personalidade;
- conclusão corporativa.

Pergunta final: **uma pessoa falaria isso jogando?**

## Visual

Reprovar quando houver:
- card para cada frase;
- bento grid gratuito;
- glassmorphism/blur/glow/degradê sem função;
- fonte padrão de template por inércia;
- hero SaaS;
- iconografia decorativa em círculos;
- tudo com o mesmo raio e sombra.

Pergunta final: **sem o logo, ainda parece Chuta Essa!?**

Se três sinais ruins aparecerem, redesenhar antes de avançar. Fonte canônica: `docs/regras-design-e-copy.md`.
