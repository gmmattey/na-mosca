# desenharInterface

Procedimento do **Giam** para UI.

Antes de desenhar, leia `docs/identidade-visual.md`, `docs/regras-design-e-copy.md`, `docs/brief-prototipo.md` e o protótipo aprovado quando existir.

Especifique apenas o necessário para o Guinho implementar:

- hierarquia;
- tipografia e escala;
- espaçamento/layout;
- estados;
- movimento;
- toque/teclado;
- acessibilidade;
- safe areas;
- comportamento responsivo.

Regras duras:

- uma tela, um protagonista;
- número e pergunta são elementos de jogo, não campos de formulário;
- não preencher vazio com card;
- não inventar gradiente/glow/blur;
- Barlow/Barlow Condensed são a direção atual até o Design System aprovar outra escolha justificada;
- antes do protótipo aprovado, não cristalizar UI final.

Se o design poderia ser de qualquer SaaS trocando o logo, devolva e redesenhe.
